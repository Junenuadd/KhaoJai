# KhaoJai (เข้าใจ)

**Learn Thai. Understand Thai. Live Thai.**
แอปเรียนภาษาไทยสำหรับชาวต่างชาติ — เวอร์ชันพรีวิวแรก เล่นได้ทันทีโดยไม่ต้องสมัครสมาชิก

- เว็บแอปตัวเดียว ใช้ได้ทั้ง iPhone, Android, Windows และ Mac ติดตั้งเป็นแอปได้ (PWA)
- ไม่ต้องสมัครสมาชิก ความคืบหน้าเก็บในเครื่องที่เล่น
- ไม่มีขั้นตอน build เป็น HTML + CSS + JavaScript ล้วน แก้ไฟล์แล้วอัปโหลดได้เลย

## มีอะไรในเวอร์ชันนี้ (v0.5 — Reading Foundations)
หัวใจของ KhaoJai คือ **สอนให้อ่านภาษาไทยออกก่อน** แล้วค่อยไปความหมาย ประโยค ไวยากรณ์ และการใช้จริง

- **สมัคร/เข้าสู่ระบบ** (อีเมล + รหัสผ่าน, ลืมรหัส, Google เมื่อเปิดใช้) ความคืบหน้าเก็บในบัญชี — หรือเล่นแบบ Guest ได้ · ดู `docs/AUTH_SETUP.md`
- **หน้าอธิบายวิธีสอน** → **คำถาม 7 ข้อ** → **แบบทดสอบวัดระดับ** (สำหรับคนที่พอรู้แล้ว) → **แดชบอร์ด**
- **Phase 1 การอ่านพื้นฐาน**: พยัญชนะ 44 ตัว (พร้อมตัวช่วยจำด้วยอักษรอังกฤษ) สลับกับสระครบทุกตัว · ประสมคำ · ตัวสะกด · อ่านโดยไม่มีคำอ่าน · ทบทวนสะสม 3 ครั้ง · สอบปลาย Phase แยก 4 ทักษะ
- **Phase 2 กฎการอ่าน**: หมู่อักษร คำเป็น/คำตาย วรรณยุกต์ ห นำ/คำควบ ตัวการันต์
- **ทุกบทมีแบบทดสอบท้ายบท** สุ่มข้อใหม่ทุกครั้ง · ไม่ผ่าน → ฝึกเฉพาะที่พลาด → สอบใหม่ · ต้องผ่านทั้งคะแนนรวมและทุกทักษะ
- **แดชบอร์ดแยกทักษะ**: แยก "เปิดดู / ฝึกแล้ว / สอบผ่าน / ทักษะแข็ง / ทักษะต้องทบทวน" และแนะนำว่าควรฝึกอะไร
- แท็บ ก–ฮ: ตาราง · สระ · ร้องตาม · ท่องและอัดเสียง · ฝึกเขียน · หมวดฝึกเขียน (ไม่บังคับ)
- รายละเอียดหลักสูตรและข้อจำกัด: `docs/CURRICULUM.md` · ระบบคำอ่าน: `docs/ROMANIZATION.md`

## โครงสร้างไฟล์
```
index.html               หน้าแอป
manifest.webmanifest     ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                    service worker (ทำงานตอนเน็ตช้า/ไม่มีเน็ต)
icons/                   ไอคอนแอป (Jai ตัวชั่วคราว)
src/styles.css           Design system ทั้งหมด (สี ฟอนต์ ปุ่ม การ์ด)
src/app.js               หน้าจอ, เส้นทางเรียน, แท็บ ก–ฮ (ตาราง/ร้องตาม/อัดเสียง/ฝึกเขียน)
src/player.js            ระบบเล่นบทเรียน (เรียน → ฝึก → เช็ก → ผลลัพธ์)
src/draw.js              กระดานฝึกเขียน + ตรวจรูปร่างแบบคร่าวๆ
src/config.js            เกณฑ์ผ่านทั้งหมด (แก้ที่นี่ที่เดียว)
src/auth.js              สมัคร/เข้าสู่ระบบ + เก็บความคืบหน้าในบัญชี (Supabase)
src/checkout.js          หน้าชำระเงิน (ตัวอย่าง)
src/store.js             เก็บความคืบหน้าในเครื่อง (จุดเดียวที่จะต่อกับเซิร์ฟเวอร์ในอนาคต)
src/ui.js                ไอคอน, มาสคอต Jai, เสียงอ่าน, toast
src/data/letters.js      พยัญชนะ 44 ตัว, ตัวช่วยจำอักษรอังกฤษ, เสียง, สระครบ
src/data/curriculum.js   Phase ทั้งหมด บทเรียน และแบบทดสอบ ← เพิ่ม/แก้บทเรียนที่นี่
src/data/beyond.js       บทสนทนาหลังผ่านพื้นฐาน
src/data/decoder.js      พจนานุกรมตัวอย่างของ Decoder
docs/DESIGN.md           แนวทางดีไซน์
docs/ROADMAP.md          แผนเฟสต่อไป + บัญชีบริการต่างๆ
docs/CURRICULUM.md       หลักสูตร กติกาปลดล็อก เกณฑ์ผ่าน ข้อจำกัด
docs/ROMANIZATION.md     ระบบคำอ่านที่ใช้ทั้งแอป
docs/AUTH_SETUP.md       ระบบบัญชีผู้ใช้ (Supabase) และสิ่งที่ต้องทำก่อนเปิดตัว
.github/workflows/pages.yml  เผยแพร่ขึ้นเว็บอัตโนมัติด้วย GitHub Pages
```

## เปิดดูบนเครื่องตัวเอง
ต้องเปิดผ่าน web server (ดับเบิลคลิกไฟล์ตรงๆ จะใช้ไม่ได้ เพราะใช้ JavaScript modules)
```bash
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

## เผยแพร่ขึ้นเว็บ (GitHub Pages)
1. ใน repo บน GitHub ไปที่ **Settings → Pages**
2. ตรง **Source** เลือก **GitHub Actions**
3. ทุกครั้งที่อัปโหลดไฟล์ใหม่เข้า `main` เว็บจะอัปเดตเองภายในประมาณ 1–2 นาที
4. ที่อยู่เว็บจะเป็น `https://junenuadd.github.io/KhaoJai/`

> GitHub Pages แบบฟรีใช้ได้กับ repo **Public** ถ้า repo เป็น Private ต้องใช้ GitHub แบบเสียเงิน หรือเปลี่ยนไปใช้ Cloudflare Pages / Netlify (ฟรี) แทน

## แก้หรือเพิ่มบทเรียน
- ข้อมูลตัวอักษร (ชื่อ คำอ่าน ความหมาย รูป เสียง หมู่): `src/data/letters.js`
