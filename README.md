# KhaoJai (เข้าใจ)

**Learn Thai. Understand Thai. Live Thai.**
แอปเรียนภาษาไทยสำหรับชาวต่างชาติ — เวอร์ชันพรีวิวแรก เล่นได้ทันทีโดยไม่ต้องสมัครสมาชิก

- เว็บแอปตัวเดียว ใช้ได้ทั้ง iPhone, Android, Windows และ Mac ติดตั้งเป็นแอปได้ (PWA)
- ไม่ต้องสมัครสมาชิก ความคืบหน้าเก็บในเครื่องที่เล่น
- ไม่มีขั้นตอน build เป็น HTML + CSS + JavaScript ล้วน แก้ไฟล์แล้วอัปโหลดได้เลย

## มีอะไรในเวอร์ชันนี้ (v0.3)
| ส่วน | รายละเอียด |
|---|---|
| **Learn (แผนที่สายรถไฟ)** | บทเรียนเรียงเป็น "สาย" และ "สถานี" มี 4 สาย 8 สถานี: Hello Line, Café Line, Chat Line, Tone Line |
| **Lesson player** | แบบฝึก 6 แบบ: เลือกคำตอบ, ฟังแล้วเลือก, จับคู่, เรียงประโยค, ตอบแชต, เลือกเสียงวรรณยุกต์ · ข้อที่ผิดจะวนกลับมาท้ายบท · แสดง/ซ่อนคำอ่านได้ · ใช้คีย์บอร์ดได้ (1–5, Enter) |
| **Practice** | Review mix, ฝึกอ่านเวลาไทยและเงิน, Tone trainer, Word cards |
| **Decoder** | ถอดภาษาแชต (พน, ป่าว, 555, มากกก) แบบไม่แก้ข้อความของผู้ใช้เอง |
| **Me** | สถิติ, วันเรียนต่อเนื่องแบบ "ดวงอาทิตย์" (ขาดได้ไม่โดนลงโทษ), เหรียญรางวัล, ตั้งค่า, วิธีติดตั้งแอป, รีเซ็ต |
| **Homework Studio** | ส่งงานเขียน/รูป/เสียง (ยังเก็บในเครื่อง ระบบตรวจจริงเป็นเฟสถัดไป) |
| **Plus + Checkout** | หน้าแพ็กเกจและหน้าชำระเงิน**ตัวอย่าง** (บัตร, PromptPay, TrueMoney, Mobile banking, Apple/Google Pay, PayPal) **ยังไม่ตัดเงินจริง** |

## โครงสร้างไฟล์
```
index.html               หน้าแอป
manifest.webmanifest     ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                    service worker (ทำงานตอนเน็ตช้า/ไม่มีเน็ต)
icons/                   ไอคอนแอป (Jai ตัวชั่วคราว)
src/styles.css           Design system ทั้งหมด (สี ฟอนต์ ปุ่ม การ์ด)
src/app.js               หน้าจอและการนำทาง
src/player.js            ระบบเล่นบทเรียน
src/checkout.js          หน้าชำระเงิน (ตัวอย่าง)
src/store.js             เก็บความคืบหน้าในเครื่อง (จุดเดียวที่จะต่อกับเซิร์ฟเวอร์ในอนาคต)
src/ui.js                ไอคอน, มาสคอต Jai, เสียงอ่าน, toast
src/data/lessons.js      เนื้อหาบทเรียนทั้งหมด ← เพิ่มสถานีใหม่ได้ที่นี่
src/data/decoder.js      พจนานุกรมตัวอย่างของ Decoder
docs/DESIGN.md           แนวทางดีไซน์
docs/ROADMAP.md          แผนเฟสต่อไป + บัญชีบริการต่างๆ
.github/workflows/pages.yml  เผยแพร่ขึ้นเว็บอัตโนมัติด้วย GitHub Pages
```

## เปิดดูบนเครื่องตัวเอง
ต้องเปิดผ่าน web server (ดับเบิลคลิกไฟล์ตรงๆ จะใช้ไม่ได้ เพราะใช้ JavaScript modules)
```bash
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

## เผยแพร่ขึ้นเว็บ (GitHub Pages)
1. ใน repo บน GitHub ไปที่ **Settings → Pages**
2. ตรง **Source** เลือก **GitHub Actions**
3. ทุกครั้งที่อัปโหลดไฟล์ใหม่เข้า `main` เว็บจะอัปเดตเองภายในประมาณ 1–2 นาที
4. ที่อยู่เว็บจะเป็น `https://junenuadd.github.io/KhaoJai/`

> GitHub Pages แบบฟรีใช้ได้กับ repo **Public** ถ้า repo เป็น Private ต้องใช้ GitHub แบบเสียเงิน หรือเปลี่ยนไปใช้ Cloudflare Pages / Netlify (ฟรี) แทน

## เพิ่มบทเรียนใหม่
เปิดไฟล์ `src/data/lessons.js`
1. เพิ่มสถานีใหม่ใน `STATIONS` (ดูตัวอย่างจาก `s1`)
2. ใส่ id ของสถานีใน `stations` ของสายที่ต้องการใน `LINES`
3. ใส่ id ลงใน `ORDER` ตามลำดับที่อยากให้ปลดล็อก
4. ถ้ามีคำศัพท์ใหม่ เพิ่มใน `WORDS`
5. เปลี่ยนเลขเวอร์ชัน `VERSION` ใน `sw.js` เพื่อให้มือถือโหลดเวอร์ชันใหม่
