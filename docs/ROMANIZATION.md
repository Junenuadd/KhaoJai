# KhaoJai romanization

KhaoJai uses one learner-friendly romanization system everywhere in the app. The romanization is shown by default in beginner lessons. Learners can hide it in Settings, or inside any lesson. The lesson R9 and the reading test start with it hidden.

**This system is an approximation.** English letters cannot show every Thai sound, and the romanization does not show tones. Tones are shown separately as a tone name (mid, low, falling, high or rising) wherever they matter. Learners should always listen to the audio as well.

## End sounds
Only eight end sounds exist:
- **k, t, p** — short and unreleased
- **n, m, ng**
- **i/y** — for ย
- **o/w** — for ว

## English-letter helpers
Each consonant also has an English helper letter (K → ก, T → ต/ท, L → ล …). These are memory aids for beginners, not romanization rules and not exact sounds.

## Letter names
A letter is named with its sound plus "or", followed by its name word. For example:
- ก ไก่ = **gor gai**
- ข ไข่ = **kor kai**
- ป ปลา = **bpor bplaa**

## Informal spellings
In real chat, people write Thai with other English spellings, such as "sawasdee ka". KhaoJai mentions these where they are useful, but always labels them as informal. The KhaoJai system above stays the reference.
