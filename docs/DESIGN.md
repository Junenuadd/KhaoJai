# KhaoJai Design — "Sunny Line"

ออกแบบเองทั้งหมด ไม่ลอก UI/UX ของแอปอื่น ได้แรงบันดาลใจด้านความรู้สึก (สดใส, เล่นแล้วสนุก, มีเกม) แต่โครงสร้างและหน้าตาเป็นของ KhaoJai

## แนวคิด
- **แผนที่สายรถไฟ** — การเรียนเป็นการ "นั่งรถไฟ" ผ่านสถานีต่างๆ แต่ละสาย = หัวข้อ, แต่ละสถานี = บทเรียน, สถานีภารกิจ (มุมเหลี่ยม + ธง) = สถานการณ์ชีวิตจริง ป้ายสถานีมีชื่อไทยกำกับเสมอ
- **ดวงอาทิตย์แทนเปลวไฟ** — วันที่เรียน = ได้ดวงอาทิตย์ ขาดวันไหนก็แค่เริ่มนับใหม่ ไม่มีบทลงโทษ ไม่มีระบบ "หัวใจหมด"
- **Jai points** — แต้มรูปกล่องคำพูด ได้จากการตอบถูกในครั้งแรก
- **คำอ่าน (romanization) เปิด/ปิดได้** ทุกข้อ เพื่อค่อยๆ ฝึกอ่านอักษรไทยจริง
- **ไอคอนเส้นเสียงวรรณยุกต์** — ปุ่มเลือกวรรณยุกต์มีเส้นแสดงระดับเสียงขึ้นลง

- ปุ่มเป็นสีพาสเทลกับตัวหนังสือสีเข้ม (contrast ผ่านมาตรฐาน) มี "ขอบล่าง" สีเข้มกว่าให้ดูกดได้
- สถานะไม่ใช้สีอย่างเดียว: ✓ / แม่กุญแจ / ข้อความกำกับเสมอ
- ธีมสว่างอย่างเดียว (ตั้งใจ ไม่ใช้โหมดมืด)

## ฟอนต์
- **Mali** — หัวข้อ (มีทั้งไทยและอังกฤษ กลมน่ารัก ฟอนต์ไทยของ Cadson Demak)
- **Nunito** — ตัวเนื้อหาภาษาอังกฤษ
- **IBM Plex Sans Thai Looped** — ภาษาไทยทุกที่ที่ผู้เรียนต้องอ่าน (แบบมีหัว อ่านง่ายสำหรับมือใหม่)

## มาสคอต
"Jai" กล่องคำพูดสีลาเวนเดอร์ เป็น**ตัวชั่วคราว** จูนจะออกแบบตัวจริงเอง — เปลี่ยนได้ที่ฟังก์ชัน `jai()` ใน `src/ui.js` และไฟล์ใน `icons/`

## Layout
- มือถือ: แถบเมนูล่าง 4 ปุ่ม (Learn / Practice / Decoder / Me)
- คอม ≥ 900px: เมนูซ้าย + แผงขวา (เป้าหมายวันนี้, คลังคำ) เมื่อจอ ≥ 1100px
- หน้าเล่นบทเรียนเต็มจอ ปุ่ม Check / Continue อยู่ล่างสุดตลอด
